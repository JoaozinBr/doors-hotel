# DOORS — protótipo 3D (Hotel+)

Jogo de terror em 3D no navegador, inspirado em DOORS. Jogue sozinho ou com amigos (até 4).

**Jogar:** abra o site do GitHub Pages deste repositório.
Personagens: no lobby, use ◀ ▶ ao lado do seu nome para escolher entre Mensageiro, Detetive, Exploradora, Médica, Pijama e Skatista.

Multiplayer: um jogador clica em **Criar sala** e passa o código; os outros digitam o código e clicam em **Entrar**.

Créditos dos modelos 3D (CC BY 4.0, Sketchfab): "doors roblox room1" por ballT_T; "Cupboard Roblox Doors" por Awaken7050; "The Figure from DOORS" por Poopo192; "figure library door 50" por grabplaytime_huggy; "Roblox Doors Seek" por Mr Elite.
